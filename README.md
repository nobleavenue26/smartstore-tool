# smartstore-tool

런던루크 / 노블애비뉴 명품 병행수입 운영 자동화 도구 모음. 순수 HTML/JS로 동작하며 서버나 설치 없이 파일을 열기만 하면 됩니다.

## index.html — 스마트스토어 일괄등록 자동화
Franz / Leam / Etique / Giglio 등 B2B 소싱처의 CSV/XLSX 카탈로그를 업로드하면 관세·부가세·개별소비세·마진·수수료를 반영해 판매가를 계산하고, 네이버 스마트스토어 상품 일괄등록용 엑셀을 생성합니다.

## product-search.html — 상품검색 · 거래처 인증
- **상품 검색 허브**: 브랜드/모델명을 입력하면 등록된 거래처 검색창과 Google/Google 이미지/Google 쇼핑/네이버쇼핑을 새 탭으로 한 번에 열어, 품절 상품을 여러 업체에서 빠르게 확인할 수 있습니다. 거래처별 검색 URL 패턴은 직접 등록/수정 가능합니다.
- **신규 거래처 인증**: 사업자등록, 정품 소싱 증빙, 온라인 평판, 운영기간, 레퍼런스, 결제조건, 샘플 검수, 커뮤니케이션 8개 항목 체크리스트로 점수(100점 만점)와 등급(승인/보류/거절)을 자동 산출하고, 검증 이력을 저장·CSV로 내보낼 수 있습니다.

모든 데이터는 브라우저 로컬 저장소(localStorage)에만 저장되며 외부로 전송되지 않습니다.
