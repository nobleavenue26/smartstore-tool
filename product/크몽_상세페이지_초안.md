## 상세 설명 본문

### 이런 분께 필요합니다

- 해외 B2B 카탈로그(CSV/엑셀)를 받아서 스마트스토어에 상품을 등록하는 **구매대행·병행수입·해외소싱 셀러**
- 상품마다 관세, 부가세, 개별소비세, 마진율, 수수료를 **엑셀로 일일이 계산**하고 있는 분
- 상품 수십~수백 개를 등록할 때마다 **상품명, 카테고리, 원산지, 태그를 손으로 채우는** 분
- 직원 없이 혼자 스토어를 운영하며 등록 시간을 줄이고 싶은 1인 셀러

### 무엇이 해결되나요

일반적인 상품 등록 과정:
```
카탈로그 확인 → 브랜드/컬러/카테고리 직접 분류 → 환율·관세·마진 계산기 따로 열어서 계산
→ 상품명 직접 작성 → 스마트스토어 양식에 하나씩 옮겨 적기
```
이 툴을 쓰면:
```
카탈로그 파일 업로드 → 자동 계산·자동 분류 → 스마트스토어 대량등록용 엑셀 다운로드 → 그대로 업로드
```

### 주요 기능

- **CSV/엑셀 업로드 한 번으로 일괄 처리** — 수십~수백 개 상품 동시 변환
- **관세·부가세·개별소비세(명품 200만원 이상)·마진율·스마트스토어 수수료** 자동 반영해 최종 판매가 산출
- **브랜드/컬러/카테고리/원산지 자동 인식** (영문 카탈로그 → 한글 변환, 스마트스토어 카테고리 코드 자동 매핑)
- **상품명 SEO 자동 생성** + 카테고리별 검색 태그 자동 삽입
- **스마트스토어 공식 대량등록 양식(93컬럼)에 맞춘 엑셀 파일**을 바로 다운로드 → 별도 가공 없이 업로드 가능
- 환율/관세율/마진율/수수료율 **전부 직접 수정 가능** (내 마진 구조에 맞게 커스터마이징)
- 설치 필요 없음, 인터넷 브라우저에서 파일 하나로 실행 (엑셀 서버로 전송되지 않고 **내 컴퓨터에서만 처리** — 원가 데이터 유출 걱정 없음)

### 사용 방법 (3단계)

1. **설정** — 스토어명/AS연락처, 환율·관세율·마진율 입력 (한 번 세팅하면 계속 재사용)
2. **파일 업로드** — 소싱처에서 받은 카탈로그(CSV/엑셀) 업로드 → 자동 계산 결과 미리보기
3. **다운로드** — 스마트스토어 대량등록용 엑셀 다운로드 → 스마트스토어센터에 그대로 업로드

## FAQ

**Q. 코딩을 몰라도 쓸 수 있나요?**
A. 네. 설치 없이 브라우저에서 파일을 열어 버튼 클릭만으로 사용합니다.

**Q. 관세/세금 계산이 실제 세관 신고 금액과 다를 수 있나요?**
A. 이 툴은 판매가 산정을 위한 참고용 계산기입니다. 실제 통관·신고 세액은 관세사를 통해 별도 확인하시기 바랍니다.

**Q. 제 소싱처 카탈로그 양식이 달라도 되나요?**
A. 일반적인 CSV/엑셀 양식은 자동 인식됩니다. 특수한 양식은 구매 후 1회 무료로 컬럼 매핑을 맞춰드립니다. [ ]

**Q. 데이터가 외부로 전송되나요?**
A. 아니요. 모든 계산은 구매자님 컴퓨터(브라우저) 안에서만 처리되고 서버로 전송되지 않습니다.
