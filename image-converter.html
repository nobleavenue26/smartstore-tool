상품 이미지 → 1000×1000 저장 도구

캡처 없이, 이미지 URL만 붙여넣으면 1000×1000 정사각형으로 자동 변환해서 저장합니다.

1-A. 이미지 URL 붙여넣기 (한 줄에 하나씩)

상품 페이지에서 각 이미지를 우클릭 → "이미지 주소 복사" 해서 여러 개를 붙여넣으세요. URL이 막혀 있는 사이트는 자동으로 프록시를 통해 한 번 더 시도합니다. 그래도 안 되면 아래 1-B(파일 업로드)를 쓰세요.

1-B. 이미지 파일 업로드 (URL이 계속 막힐 때 가장 확실한 방법)

여기로 이미지 파일을 끌어다 놓거나 클릭해서 선택하세요.

사이트에서 이미지를 우클릭 → "이미지를 다른 이름으로 저장"으로 내려받은 뒤 여기에 올리면, CORS 제한과 상관없이 항상 변환됩니다.

URL 변환은 이 브라우저 안에서만 이뤄지고, 이미지는 이 페이지 외에는 전송되지 않습니다. 단, 사이트가 CORS로 직접 접근을 막아둔 경우 images.weserv.nl 이미지 프록시를 통해 한 번 더 시도하며, 이때는 해당 이미지가 프록시 서버를 거칩니다. 그래도 실패하면 이미지 파일을 직접 다운로드해 1-B에 업로드하세요 (완전히 로컬에서만 처리됩니다). 저작권/사용 권한이 있는 이미지(자사 상품, 공급사 제공 이미지 등)만 변환해 사용하세요.
